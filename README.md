# Gildea-House
Anything and everything in the household 
What works

• Household tasks and grocery lists
• Family-board note
• Calendar events
• Dinner roulette
• Household mood
• A customizable countdown
• Confetti, for legitimate or completely fabricated achievements

Everything entered in the hub is saved with browser storage on that device. It is not committed to GitHub and does not sync between phones. A future shared version can connect to a separate household database.
